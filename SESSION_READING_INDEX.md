## 🔑 CRITICAL DISCOVERIES

### **Universal Truths** (Both Programmers Learned)

1. **"PARAR e Planejar" (Stop and Plan)**
   - 5 minutes planning > 4 hours debugging later
   - Investigation is BLOQUEANTE (mandatory first step)

2. **Protocol 3 is Non-Negotiable**
   - Violation cost: 10+ hour infinite test loop
   - Rule: Always timeout + headless for GUI tests

3. **i18n Golden Rule**
   - Use `currentData()` for logic, `currentText()` for display
   - Every i18n bug traces back to this principle

4. **Threading is Mandatory**
   - Any operation >100ms MUST be threaded
   - Batch size: 100 items optimal
   - Pattern: QThread + Worker + signals

5. **Progressive Enhancement Wins**
   - Ship 70% solution today (quick fix)
   - Plan 95% solution next session (proper fix)
   - Defer 100% solution to v3.0 (optimal fix)

6. **Error Handling Protects Sleep**
   - Global exception handlers catch surprises
   - User-friendly dialogs (not scary traces)
   - Privacy-aware crash reports

7. **Explicit References > Parent Chains**
   - Qt auto-reparents widgets
   - Use explicit `_main_window_ref` as primary
   - Fallback to parent chain for safety
