JSX/TSX parameter and attribute extraction parsers.

Author: Josué Amaral Date: 2025-12-02

class src.extractors.JSXParser(param_name: str, match_all: bool = False, is_attribute_mode: bool = False, no_standard: bool = False)[source]

Bases: object

Minimal JSX-ish parser to:

  • detect opening tags <Tag …> and self-closing <Tag …/>

  • detect closing tags </Tag>

  • detect attributes on opening/self-closing token (key=”…” | key={’…’} | key={…expr…})

It builds a stack of open tag names. For each opening/self-closing tag, if the attribute target matches (–param), we emit a record with the current path + tag, and attr value.

This is robust enough for common .tsx/.jsx files (not a full parser).

class src.extractors.GenericScopeParser(param_name: str, start_regex: str, end_regex: str, match_all: bool = False)[source]

Bases: object

Generic parser driven by user regex for scope start and end (delimiters). When a start match occurs, push a name for that scope (if we can infer a label), else push a generic token like ‘scope’. For simplicity, we allow user to define a name-capture group (?P<name>…) inside start regex to be used as node name; otherwise we fallback to a token ‘scope’.

We also scan inside each start token for attributes like key=”…” etc (like JSXParser).
