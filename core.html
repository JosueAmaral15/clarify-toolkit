Extract content within specified scope delimiters.

  • scope_type – Type of scope (“brackets”, “braces”, “custom”, “tag”, “specific-tag”, “hierarchical”, “” for no scope)

Hierarchical Ranges Syntax (scope_type=”hierarchical”):

“include div#test1, exclude #test2, include #test3” - include: Add matching content - exclude: Remove matching content from results - Supports: #id, tag#id, tag, regex patterns

src.core.cli_dedupe(args: Namespace, advanced_conditions: list[Condition] | None = None, apply_all_types: bool = False)[source]

Execute the dedupe/rewrite operation based on args.

Parameters:

  • args – Command-line arguments (or GUI-generated args)

  • advanced_conditions – Optional list of Condition objects for filtering files (Sprint B Feature #1)

  • apply_all_types – If True, apply filters to all files; if False, auto-detect .json (Sprint B Feature #1)

Returns:

(output_text, substitution_map, removal_stats, detailed_stats) where:

  • output_text: processed file content

  • substitution_map: maps removed keys to replacements (Task #23)

  • removal_stats: dict with removal counters (Task v2.9.22)

  • detailed_stats: list of DetailedStatEntry objects (Sprint B Feature #3 v2.9.31)

Return type:

tuple
