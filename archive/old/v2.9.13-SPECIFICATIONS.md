### Task #40: Context Menu - File List  
**Complexity**: 20min  
**Status**: ✅ Completed  
**Files**: `src/gui/file_list_dock.py`

**Description**:  
Adiciona menu de contexto ao clicar com botão direito em linhas da tabela File List. Suporta seleção múltipla E seleção única conforme escolha do usuário.

**Features**:
- Menu de contexto ativado com botão direito do mouse
- Suporte para seleção múltipla (Ctrl+Click / Shift+Click)
- Ação "Open in File Manager" para uma seleção
- Ação "Open X Locations in File Manager" para múltiplas seleções
- Integração multiplataforma:
  - Windows: `os.startfile()`
  - macOS: `subprocess.run(["open", ...])`
  - Linux: `subprocess.run(["xdg-open", ...])`
- Abre diretório pai do arquivo selecionado

**Technical Details**:
```python
# Context menu setup
self.table.setContextMenuPolicy(Qt.ContextMenuPolicy.CustomContextMenu)
self.table.setSelectionMode(QTableWidget.SelectionMode.ExtendedSelection)
self.table.customContextMenuRequested.connect(self._show_context_menu)

# Menu display
def _show_context_menu(self, position):
    selected_rows = set(item.row() for item in self.table.selectedItems())
    if not selected_rows:
        return
    menu = QMenu(self)
    action_text = ("Open in File Manager" if len(selected_rows) == 1 
                   else f"Open {len(selected_rows)} Locations in File Manager")
    action = QAction(action_text, self)
    action.triggered.connect(self._open_in_file_manager)
    menu.addAction(action)
    menu.exec(self.table.viewport().mapToGlobal(position))

# Platform-specific file manager opening
def _open_in_file_manager(self):
    for row in sorted(set(item.row() for item in self.table.selectedItems())):
        path_item = self.table.item(row, 4)
        if path_item:
            filepath = path_item.text()
            directory = os.path.dirname(filepath) if os.path.isfile(filepath) else filepath
            system = platform.system()
            if system == "Windows":
                os.startfile(directory)
            elif system == "Darwin":
                subprocess.run(["open", directory])
            else:  # Linux
                subprocess.run(["xdg-open", directory])
```

**User Requirements Met**:

### Task #41: Tooltip Preview - Advanced Search  
**Complexity**: 25min  
**Status**: ✅ Completed  
**Files**: `src/utils/file_finder.py`

**Description**:  
Adiciona preview de arquivos em tooltip ao passar mouse sobre linhas de resultado na busca avançada. Mostra as primeiras 3 linhas do arquivo com limite de 200 caracteres.

**Features**:
- Tooltip ativado ao passar mouse sobre células da tabela
- Mostra preview apenas para arquivos (não diretórios)
- Lê primeiras 3 linhas do arquivo
- Trunca em 200 caracteres com "..." se exceder
- Tratamento de erros de leitura (encoding, permissão, etc.)
- Mensagem "(empty file)" para arquivos vazios
- Mensagem "Directory" para pastas

**Technical Details**:
```python
# Enable mouse tracking
self.table.setMouseTracking(True)
self.table.itemEntered.connect(self._show_file_preview)

# Preview method
def _show_file_preview(self, item: QTableWidgetItem):
    if not item:
        return
    
    row = item.row()
    if row >= len(self.results):
        return
    
    filepath, stat = self.results[row]
    
    if not os.path.isfile(filepath):
        item.setToolTip("Directory")
        return
    
    try:
        with open(filepath, 'r', encoding='utf-8', errors='ignore') as f:
            lines = []
            char_count = 0
            for _ in range(3):
                line = f.readline()
                if not line:
                    break
                lines.append(line.rstrip())
                char_count += len(line)
                if char_count >= 200:
                    break
            
            preview = '\n'.join(lines)
            if char_count >= 200:
                preview = preview[:200] + "..."
            
            item.setToolTip(preview if preview else "(empty file)")
    except Exception as e:
        item.setToolTip(f"Could not read file: {e}")
```

### Task #42: Save Preferences - File List  
**Complexity**: 30min  
**Status**: ✅ Completed  
**Files**: `src/gui/file_list_dock.py`

**Description**:  
Salva preferências do usuário (estados dos checkboxes) e últimos 10 diretórios usados. Adiciona botão "Recent" para acesso rápido aos diretórios recentes.

**Features**:
- Persistência de estados dos checkboxes:
  - Show hidden files (-a)
  - Long format (-l)
  - Human-readable sizes (-h)
  - Recursive (-R)
- Lista de últimos 10 diretórios (FIFO queue)
- Botão "Recent ▼" com menu dropdown
- Menu "Recent" com:
  - Lista dos 10 últimos diretórios
  - Separador
  - Opção "Clear Recent"
- Salva automaticamente após listar arquivos
- Carrega preferências ao iniciar aplicação
- Usa QSettings para armazenamento nativo

**Technical Details**:
```python
# Initialization
def __init__(self, parent=None):
    super().__init__("File List", parent)
    self.settings = QSettings("Clarify", "FileList")
    self._load_preferences()

# Load preferences
def _load_preferences(self):
    self.chk_all_state = self.settings.value("show_hidden", False, type=bool)
    self.chk_long_state = self.settings.value("long_format", True, type=bool)
    self.chk_human_state = self.settings.value("human_readable", True, type=bool)
    self.chk_recursive_state = self.settings.value("recursive", False, type=bool)
    self.recent_dirs = self.settings.value("recent_directories", [], type=list)
    if not isinstance(self.recent_dirs, list):
        self.recent_dirs = []

# Save preferences
def _save_preferences(self):
    self.settings.setValue("show_hidden", self.chk_all.isChecked())
    self.settings.setValue("long_format", self.chk_long.isChecked())
    self.settings.setValue("human_readable", self.chk_human.isChecked())
    self.settings.setValue("recursive", self.chk_recursive.isChecked())
    self.settings.setValue("recent_directories", self.recent_dirs)

# Add to recent (FIFO queue, max 10)
def _add_to_recent(self, directory: str):
    if directory in self.recent_dirs:
        self.recent_dirs.remove(directory)  # Move to top if exists
    self.recent_dirs.insert(0, directory)
    self.recent_dirs = self.recent_dirs[:10]  # Keep only last 10
    self._save_preferences()

# Recent menu
def _show_recent_menu(self):
    if not self.recent_dirs:
        QMessageBox.information(self, "No Recent Directories", 
                               "No recent directories saved yet.")
        return
    
    menu = QMenu(self)
    for directory in self.recent_dirs:
        action = QAction(directory, self)
        action.triggered.connect(lambda checked, d=directory: self.ed_directory.setText(d))
        menu.addAction(action)
    
    menu.addSeparator()
    clear_action = QAction("Clear Recent", self)
    clear_action.triggered.connect(self._clear_recent)
    menu.addAction(clear_action)
    menu.exec(self.btn_recent.mapToGlobal(self.btn_recent.rect().bottomLeft()))

def _clear_recent(self):
    self.recent_dirs = []
    self._save_preferences()
    QMessageBox.information(self, "Cleared", "Recent directories list cleared.")

# Apply saved states to checkboxes
self.chk_all.setChecked(getattr(self, 'chk_all_state', False))
self.chk_long.setChecked(getattr(self, 'chk_long_state', True))
self.chk_human.setChecked(getattr(self, 'chk_human_state', True))
self.chk_recursive.setChecked(getattr(self, 'chk_recursive_state', False))
```

**QSettings Keys**:
- `show_hidden` (bool): Show hidden files state
- `long_format` (bool): Long format state
- `human_readable` (bool): Human-readable sizes state
- `recursive` (bool): Recursive search state
- `recent_directories` (list): Last 10 directories (FIFO)

### Task #43: Stats Label - JSON Translate  
**Complexity**: 15min  
**Status**: ✅ Completed  
**Files**: `src/gui/json_translate_dock.py`

**Description**:  
Adiciona label de estatísticas mostrando quantos arquivos serão processados e quantas traduções estão disponíveis no dicionário. Atualiza automaticamente conforme usuário altera os campos.

**Features**:
- Label dinâmica de estatísticas
- Mostra "X file(s) to process | Y translation(s) available"
- Atualiza em tempo real ao digitar no path ou dictionary
- Contagem inteligente:
  - Arquivo único: conta 1
  - Diretório: usa walk_files com exclusões (node_modules, .git, dist, build)
  - Dicionário: conta chaves do objeto JSON/TS
- Posicionado acima dos botões de ação (Row 9)
- Estilo cinza e itálico para indicar status informativo
- Mensagem "Ready" quando campos vazios

**Technical Details**:
```python
# Widget creation
self.lbl_stats = QLabel("Ready")
self.lbl_stats.setStyleSheet("color: gray; font-style: italic;")
self.lbl_stats.setWordWrap(True)

# Layout positioning (above action buttons)
g.addWidget(self.lbl_stats, 9, 0, 1, 4)  # Full width, row 9
# Buttons moved to row 10

# Signal connections
self.ed_path.textChanged.connect(self._update_stats)
self.ed_dict.textChanged.connect(self._update_stats)

# Update method
def _update_stats(self):
    path = self.ed_path.text().strip()
    dict_path = self.ed_dict.text().strip()
    
    if not path and not dict_path:
        self.lbl_stats.setText("Ready")
        return
    
    file_count = 0
    translation_count = 0
    
    # Count files
    if path:
        if os.path.isfile(path):
            file_count = 1
        elif os.path.isdir(path):
            try:
                paths = list(walk_files(path, include_globs=None,
                                       exclude_globs=["node_modules", ".git", "dist", "build"]))
                file_count = len(paths)
            except Exception:
                file_count = 0
    
    # Count translations
    if dict_path and os.path.isfile(dict_path):
        try:
            dictionary = load_translation_dict(dict_path)
            translation_count = len(dictionary) if isinstance(dictionary, dict) else 0
        except Exception:
            translation_count = 0
    
    # Update label
    if file_count > 0 or translation_count > 0:
        parts = []
        if file_count > 0:
            parts.append(f"{file_count} file{'s' if file_count != 1 else ''} to process")
        if translation_count > 0:
            parts.append(f"{translation_count} translation{'s' if translation_count != 1 else ''} available")
        self.lbl_stats.setText(" | ".join(parts))
    else:
        self.lbl_stats.setText("Ready")
```

**User Requirements Met**:
- ✅ "X files to process | Y translations found"
- ✅ "Posicione onde achar melhor e for para uma UI/UX de qualidade" (positioned above buttons)
- ✅ Updates after input validation (on textChanged)
- ✅ Real-time feedback

**UI Positioning Decision**:
Positioned in **Row 9** (above action buttons) for optimal UX because:

- Natural read order: inputs → stats → actions
- Doesn't interfere with existing layout
- Provides immediate feedback while filling fields
- Similar to status bars in other professional tools
