Utilities

Utility modules for file operations, text processing, and TypeScript handling.

Utility functions for file operations, text processing, and TypeScript/JavaScript handling.

src.utils.walk_files(root: str, include_globs: Sequence[str] | None = None, exclude_globs: Sequence[str] | None = None) → Iterator[str][source]

Recursively yield files under ‘root’ (file or directory). Uses fnmatch-style glob filters. - include_globs: if provided, file path must match at least one of them (relative or absolute). - exclude_globs: if provided, file path must NOT match any of them.

src.utils.read_text(path: str, max_bytes: int | None = None) → str[source]

Read text file with UTF-8 fallback to latin-1.

src.utils.write_text(path: str, content: str) → None[source]

Write text to file, creating parent directories if needed.

src.utils.safe_backup_file(path: str) → None[source]

Create path.bak once. If already exists, do not overwrite.

src.utils.parse_exclusion_patterns(csv_regex: str) → list[str][source]

Split a comma-separated regex list into individual non-empty patterns.

src.utils.mask_exclusions(text: str, patterns: list[str]) → tuple[str, list[str]][source]

Replace each region matched by any exclusion regex with a guard token @@XCL{n}@@. Returns (masked_text, guards) where guards[i] is the original match.

src.utils.unmask_exclusions(text: str, guards: list[str]) → str[source]

Restore masked exclusions to original text.

src.utils.compile_value_union_regex(value_to_key: dict[str, str]) → Pattern[source]

Build a single alternation regex with named groups for each value. Sort by length (desc) to prefer the longest phrase first.

src.utils.load_ts_object(text: str) → dict[source]

Parse a TS/JS object (export default { … } or { … }) to dict safely.

src.utils.dump_ts_object(obj: dict, emit_export_default: bool = True, indent: int = 2) → str[source]

Deterministic pretty TS object: single-quoted strings, sorted keys, optional export default.

src.utils.strip_export_default(src: str) → str[source]

Remove a leading export default (if present).

src.utils.to_json_ish(src: str) → str[source]
Convert a TS object literal into valid JSON:

  • Ensure keys are quoted

  • Convert single-quoted strings → double-quoted

  • Remove trailing commas

  • Remove optional semicolon at end

This is not a full JS parser, but works for object/array/string/number/bool/null.

src.utils.format_removal_statistics(stats: dict) → str[source]

Format removal statistics for display.

Parameters:

stats – Dictionary with removal counters

Returns:

Formatted string or empty string if nothing was removed
