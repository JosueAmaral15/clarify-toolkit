src.rewriter.build_substitution_map_by_value(old_keys_values: Dict[str, str], new_keys_values: Dict[str, str]) → Dict[str, str][source]

Build substitution map based on VALUE EQUALITY (not string similarity).

Strategy (conforme especificações do usuário): 1. Identify removed keys: keys in old but not in new 2. For each removed key, find new key with SAME VALUE (identical) 3. Priority rules:

  1. Prefer key with same parent path (t.pages.contact > t.pages.contactPage)

  2. If multiple candidates, use first one (linha menor vence)

  3. Do NOT touch if values are different

  4. Same key in different paths is OK (different full paths)

Parameters:

  • old_keys_values – Dict of path → value BEFORE elimination

  • new_keys_values – Dict of path → value AFTER elimination

Returns:

Dict mapping removed_path → kept_path (only for IDENTICAL values) Example: {‘t.pages.contactPage.title’: ‘t.pages.contact.title’}

User Requirements: - “Se ocorrer duas chaves com valores redundantes, e se marcado que se deve

eliminar redundâncias, então a chave/objeto/caminho mais abaixo do arquivo deve ser eliminado, ou seja, apagado do arquivo.”

  • “Se essas chaves estão em paths diferentes, ou seja, de pais chaves ou ancestrais chaves diferentes, ainda sim devem ser eliminados caso houver redundâncias de valores.”

  • “E se houver chaves iguais com valores diferentes, deixa quieto, não mexa!”

  • “Não mexa se tiverem a mesma chave em caminhos diferentes, somente se estiverem com a mesma chave pai.”
