# Format Preservation - Quick Reference Card

**Quick Guide** | Clarify Google Translate Tool | v2.9.117+

---

## 🚀 3-Step Translation

```
1. Open File → Load DOCX/ODT
2. Select Languages → Source & Target
3. Translate & Save → Choose format
```

**Done!** Formatting automatically preserved ✨

---

## ✅ What's Preserved (35 formats)

### Text Formatting
- ✅ **Bold**, *Italic*, <u>Underline</u>
- ✅ ~~Strikethrough~~, Colors, Sizes, Fonts
- ✅ Highlight, x², H₂O

### Paragraph
- ✅ Alignment (Left/Center/Right/Justify)
- ✅ Spacing (Line spacing, paragraph spacing)
- ✅ Indentation (First line, margins)

### Structure
- ✅ Headings (H1-H6)
- ✅ Lists (Bullets, Numbers, Multi-level)
- ✅ Hyperlinks (All types)

### Special
- ✅ Non-breaking spaces/hyphens
- ✅ Tabs, Unicode characters

---

## ❌ Not Yet Supported

- ❌ Tables (future)
- ❌ Images (can't translate)
- ❌ Custom styles (future)
- ❌ Page layout (future)

## 💡 Quick Tips

### Best Practices
✅ Use standard fonts (Arial, Times)  
✅ Save in same format (DOCX→DOCX)  
✅ Keep backups of originals  
✅ Test one document first

### Performance
- Small docs (< 10 pages): Instant
- Medium docs (10-50 pages): Few seconds
- Large docs (50+ pages): 30+ seconds

---

## 🔧 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Formatting looks different | Use common fonts |
| Some text lost format | Check if format is supported |
| Translation slow | Normal for large/formatted docs |
| Can't open saved file | Use format dropdown in save dialog |
